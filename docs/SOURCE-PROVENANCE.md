# Source provenance

Prepared from the latest scene-map working directory, which extends the Green Hour Netlify source. The reference archive green-hour-netlify-dist.zip contains 47 entries. Earlier archives remain in the original outputs folder and are not duplicated in this repository.

The latest in-the-life-of and skeletons-in-the-closet pages are included. Disco and architecture entry pages are preserved. The old two-card combined map is retained at /map/; the newer cards have not been integrated into it. Opening-title and take-it-to-the-grave studies are retained as separate optional pages.

Blender source files remain outside the web repository. Exported web GLBs and images are included. Export scripts retain their source scene requirements; see their own card READMEs. No original files were moved or overwritten.
